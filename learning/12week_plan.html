Python × LLM 自動QA — 12週間プラン

本当の初心者から、3ヶ月で「LLMがアノテーションを自動採点するツール」を作るまで。週10時間ペース。
🎯 ゴール： 自分のガイドラインに照らして、LLMがアノテーションの品質を自動採点するツールを完成させる。
これは ① 学習のゴール × ② 就職の証拠（Mercor等）× ③ 自分の事業の道具 を全部兼ねる。
🟢 フェーズ1：Pythonの土台（1〜3週）
Week 1基本のキ
学ぶ変数・文字列・リスト・print（Colabの使い方）
作るレッスン1の自動QAチェックに、自分で例を足して動かす
📘 Python for Everybody（Ch.1–5）
Week 2繰り返しと条件
学ぶfor ループ・if文・関数（def）
作るcheck(caption) と書いたら問題を返す「ミニQA関数」
📘 Python for Everybody（Ch.6–8）
Week 3データのまとめ方
学ぶ辞書（dict）・リストの中に辞書
作る1件を {"id":.., "caption":..} で扱い、複数件を一括チェック
📘 Python for Everybody（Ch.9–10）＋ Kaggle「Python」
🟡 フェーズ2：本物っぽいデータを扱う（4〜6週）
Week 4pandas入門
学ぶ表（DataFrame）の読み込み・表示・列の操作
作るCSVのデータを読んで、件数や平均文字数を集計
📘 Kaggle「Pandas」コース
Week 5集計とフィルタ
学ぶ絞り込み・グループ集計・並べ替え
作る「担当者ごとの問題件数」「短すぎる一覧」を自動出力
📘 Kaggle 続き
Week 6SQL入門
学ぶSELECT・WHERE・JOIN・GROUP BY
作る同じ集計をSQLでも（DBから品質指標を引く感覚）
📘 SQLBolt（全部）＋ Mode SQL Tutorial
🟠 フェーズ3：LLMに仕事をさせる（7〜9週）
Week 7LLM APIに触る
学ぶAPIキー・LLMにメッセージを送って返事をもらう仕組み
作るPythonから「このキャプションを評価して」とLLMに聞く
📘 Anthropic（Claude）公式ドキュメント＋Cookbook
Week 8プロンプト設計
学ぶ指示の書き方・構造化出力（JSONで返させる）
作る「スコア(1-5)と理由をJSONで返して」と頼むスクリプト
📘 Anthropic プロンプトガイド
Week 9LLM-as-a-judge
学ぶガイドラインをプロンプトに入れて基準で採点させる
作る自分のGLを渡して、キャプションを自動採点（事業の心臓部）
📘 DeepLearning.AI のLLM評価系ショートコース
🔵 フェーズ4：本物のツールに仕上げる（10〜12週）
Week 10つなげる
学ぶpandas × LLM を組み合わせる
作るCSVを読む → 1行ずつLLM採点 → 結果を新しい列に保存
Week 11レポート化
学ぶ集計＋簡単なグラフ（matplotlib）
作る平均スコア・低スコアTOP10・よくある問題を自動レポート
Week 12仕上げ＆ポートフォリオ化
学ぶコードを整理・READMEを書く
