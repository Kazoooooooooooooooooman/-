# Sumi Phone

墨絵の世界観でつくった、デジタルデトックス・スマートフォン「Sumi（仮称）」のランディングページ。

- スクロールすると背景が 山 → 竹林 → 湖 → 海 → 枯山水 → 温泉 → 渓流 → 雪松 → 星空 と切り替わる
- 背景の上に白くシンプルな文字
- 「ホーム」セクションでは、用事のボタンを押すと端末の画面が切り替わる（写真だけカラー表示）

`index.html` をブラウザで直接開くだけで動きます。

背景画像（`images/`）は、このサイトのために numpy でプログラム生成した墨絵風の画像です（外部素材は使っていません）。

背景を作り直すとき: `python3 tools/gen_backgrounds.py images`（numpy と Pillow が必要です）
