# Soto Phone（仮称）

「楽しみは、画面の外に。」 SNS もゲームもない、必要な道具だけを持ち歩くデジタルデトックス・スマートフォンの紹介ページ。

## ページの流れ

- 1枚目：キャッチコピー「スマホを置いた時間で、新しい自分を作ろう。」（最後の先行予約は「楽しみは、画面の外に。」）
- 絵本の章（白黒の紙）：手描きスケッチから起こした物語
  - 机の前で終わりのないフィードをスワイプし続ける絵（フィードと指が動き続ける）
  - 部屋の絵では、窓の外が太陽から月へ変わり、夜はスマホの光だけが顔を照らす一日がくり返す
  - 絵の具が一滴落ちて、白黒の紙に最初の色がにじむ（スクロールで進む）
- 後半（手描きの線と水彩）：丘 → 湖 → 温泉 → 渓流 → 山 → 夕焼けの海と、だんだん色が増えていく
  - Soto Phone とは／入っている道具／ポイント／ショップ／かたち／先行予約
- 先行予約の登録フォーム（claude.ai の公開ページでは登録をページのデータベースに保存。ファイルを直接開いたときは保存されない）

コンセプト：必要な道具だけを持ち歩く電話。SNS・ゲーム・銀行・メール・QR 決済は入れず、支払いは実物のカード、ほかの用事はパソコンで。

`index.html` をブラウザで直接開くだけで動きます。

## 画像の作り直し

- 後半の水彩の背景：`python3 tools/gen_watercolor.py images`（numpy と Pillow が必要）
- 絵本ページの紙：`python3 tools/gen_backgrounds.py images 10-paper`
- スケッチの切り出し：`python3 tools/clean_sketches.py images/story`（pillow-heif が必要。元の HEIC の場所はスクリプト内で指定）
