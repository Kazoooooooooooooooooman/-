受験が近づくと、スマホをどうするかで迷います。解約するか、親に預けるか、ガラケーに替えるか。どれが正しいかは、その人がスマホで何をしてしまうかで決まります。この記事では、受験期のスマホの扱い方を5つに分けて比べ、解約や機種変更の前に確かめることと、親子でルールを決めるときのコツをまとめます。

先に結論

  • 高校生のネット利用は、平日1日あたり約6時間44分（2025年度）。何もしなければ、受験勉強の時間はスマホに負ける
  • 選び方は「何をしてしまうか」で決める。SNS や動画が止まらないなら、ルールより道具を替えるほうが効く
  • 解約は最後の手段。出願、合格発表、学校や塾の連絡、ログインの確認コードに困らないか、先に確かめる
  • 親子のルールは、子どもが自分で決めて、期限を「受験が終わる日」にする。親も同じルールを守る

受験生は、スマホにどれくらい時間を使っているか

こども家庭庁の2025年度の調査では、平日1日あたりのインターネットの利用時間は、高校生で約6時間44分、中学生で約5時間24分でした。どちらも、この調査で過去最長です。ここにはスマホのほか、パソコンやゲーム機などでの利用も含まれます。

一方で、勉強の時間は減っています。東京大学とベネッセ教育総合研究所の親子調査では、学校の外での学習時間（宿題、家庭学習、塾の合計）が、2015年から2025年の間に高校生で1日22分、中学生で19分減りました。宿題以外の家庭学習をまったくしない子どもは、4〜5割になっています。

スマホの時間が増えたことだけが原因とは言えません。それでも、1日は24時間しかありません。受験生にとって、スマホの時間はそのまま勉強の時間の取り合いになります。

受験期のスマホの扱い方は5つ

選べる方法は、大きく分けて5つです。上ほど手軽で、下ほど効き目が強く、そのぶん困ることも増えます。

方法効き目困ること向いている人
1. ルールを決めて使う弱い守れないと意味がないスマホの時間が、もともと短い人
2. 時間を決めて預ける中くらい預かる人が要る。返す時間でもめやすい家にいる時間に触ってしまう人
3. アプリを消して、制限をかける中くらい自分で入れ直せる。制限を解除してしまう特定のアプリだけが問題の人
4. ガラケーやミニマルフォンに替える強いLINE や一部のアプリが使えないことがあるSNS・動画・ゲームがやめられない人
5. 解約するいちばん強い電話番号やログインに困る。連絡がとりにくい外での連絡が、ほとんど要らない人

1. ルールを決めて使う

「夜10時以降は使わない」「勉強中は別の部屋に置く」のように決めて、スマホはそのまま使います。いちばん手軽ですが、いちばん崩れやすい方法です。触る時間が1日1〜2時間ほどに収まっている人なら、これで足ります。勉強中の置き場所や通知の止め方は、勉強中にスマホを触ってしまうのをやめる方法にまとめています。

2. 時間を決めて預ける

平日の夜や休日の勉強時間だけ、家族にスマホを預けます。自分で自分を止めなくてよいので、ルールより確実です。決めておくことは3つです。

  • 預ける時間：「帰宅してから夜9時まで」のように、時刻で決める
  • 返す条件：「勉強が終わったら」ではなく、「9時になったら」にする。条件をあいまいにすると、毎晩もめる
  • 例外：塾の連絡や、学校の課題で使うときの扱いを先に決めておく

家族に預けにくいなら、時間が来るまで開かない鍵付きの箱を使う方法もあります。

3. アプリを消して、制限をかける

SNS・動画・ゲームのアプリを消し、iPhone のスクリーンタイムや Android のファミリーリンクで、入れ直せないようにします。電話・地図・学校の連絡など、必要なものは残せます。

弱点は、解除できてしまうことです。パスコードを自分で決めると、つらいときに自分で外します。パスコードは保護者が決めて、本人は知らないようにするのが前提です。解除してしまう理由と防ぎ方は、スクリーンタイムを自分で解除してしまう人へで詳しく書いています。また、ブラウザが使えるかぎり、アプリを消しても SNS や動画は見られます。

4. ガラケーやミニマルフォンに替える

受験が終わるまで、電話と SMS が中心の携帯に持ち替えます。SNS や動画が入らない機種なら、入れ直しも解除もできません。「やめたいのに、やめられない」人には、いちばん効く方法です。

やり方は2通りあります。今のスマホの SIM を携帯に入れ替える方法と、スマホは家に置いたまま、外に持つ携帯をもう1台用意する方法です。後者なら、スマホは家族に預けたまま、調べものや出願のときだけ使えます（スマホを家に置いて出かける「2台持ち」のやり方）。

注意したいのは LINE です。今の4Gケータイの多くは LINE が使えないか、使える機能が限られます。クラスや部活、塾の連絡が LINE だけで回っているなら、替える前に連絡方法を決めておきます（LINE を使わずに連絡する方法、ガラケーは2026年も使える？）。

5. 解約する

スマホの契約そのものをやめます。持っていなければ、触ることもありません。ただし、解約すると電話番号がなくなります。番号を残したいなら、ドコモの「電話番号保管」のように、使わない間も番号を残しておけるサービスがあります。料金や条件は携帯会社ごとに違うので、申し込む前に確かめてください。

解約は効き目が強い分、あとで困ることも多い方法です。次の章のことを確かめてから決めてください。

解約や機種変更の前に確かめること

受験期は、スマホでしか届かない連絡が意外と多い時期です。替える前に、次のものがスマホなしで回るかを確かめます。

  • 出願：大学入学共通テストは、令和8年度（2026年1月の試験）から出願がオンラインになりました。パソコンやタブレットでも手続きできるので、家族のパソコンを使えば足ります
  • 合格発表：Web で発表する大学もある。これもパソコンで見られる
  • 確認コード：出願サイトや塾のアプリで、ログインのたびに SMS で確認コードが届くことがある。番号を残すか、届く先をメールに変えておく
  • 学校と塾の連絡：連絡が LINE やアプリだけで届くなら、メールや電話でも受け取れるよう先生に頼んでおく
  • 家族との連絡：塾の帰りや試験当日に、電話と SMS ができる手段は残す
  • 写真とデータ：解約や機種変更の前に、写真と LINE のトーク履歴をバックアップしておく

このうち、出願と合格発表は家のパソコンで済みます。外で必要なのは、電話・SMS・地図くらいです。受験生が外に持ち歩く道具に、SNS は要りません。

親子でルールを決めるときのコツ

イギリスの学校を調べた研究（Beland と Murphy、2015年）では、学校がスマホの持ち込みを禁止したあと、生徒の大事な試験の成績が上がりました。伸びが大きかったのは、もともと成績が低めだった生徒です。一方で、禁止がきちんと守られていない学校では、はっきりした効果は出ませんでした。ルールは、作ることより守られることで効きます。家庭でも同じです。

守られるルールにするために、次の5つを押さえます。

  1. 子どもが自分で決める：親が決めたルールは、親が見ていないところで破られる。5つの方法のどれにするかを、本人に選んでもらう
  2. 期限を決める：「受験が終わる日まで」と終わりを決める。終わりが見えると、続けやすい
  3. 紙に書いて貼る：時間、場所、例外を紙に書いて、家族の見える所に貼る。言った言わないでもめなくなる
  4. 親も同じルールを守る：子どもが預けている時間に、親がリビングでスマホを見ていたら続かない
  5. 破ったときのことを先に決める：叱るのではなく、「破ったら、次の方法に進む」と決めておく。ルールで続かなければ預ける、預けても続かなければ携帯を替える、という順番にする

保護者が気をつけたいのは、取り上げるだけで終わらせないことです。受験生にとってスマホは、友だちとの数少ない息抜きでもあります。週末の夜に1時間など、使っていい時間を決めておくと、隠れて使うことが減ります。

受験までの時期ごとの目安

  • 受験の1年前〜夏：まずは1か2で始める。続かなければ3に進む
  • 秋（受験の3〜4か月前）：模試の結果を見て決め直す。スマホの時間が減っていなければ、4の携帯への持ち替えを考える。替えるなら、出願の手続きが始まる前に済ませておく
  • 直前期（1〜2か月前）：新しいことは始めない。今の方法を続ける。機種変更や解約は、この時期にはしない
  • 受験が終わったら：決めておいた期限どおりに元に戻す。そのうえで、受験期の使い方で困らなかったことは、そのまま続けてもいい

よくある迷い

スマホを手放すと、友だちの輪から外れないか

受験期は、まわりの友だちも同じように忙しい時期です。「受験が終わるまで LINE は夜しか見ない」「急ぎは電話で」と先に伝えておけば、困ることはほとんどありません。伝えずに急に返事が遅くなるほうが、誤解を生みます。仲のいい友だちと一緒に始めるのも、1つの方法です。

単語アプリや映像授業は、どうするか

勉強のアプリは、スマホを使う理由として、いちばんよく挙がるものです。ただ、単語アプリを開いたついでに SNS を開いてしまうなら、勉強のアプリが入口になっています。映像授業は家のパソコンかタブレットで見る、単語は紙の単語帳にする、のように、勉強に使う画面と遊ぶ画面を分けます。タブレットにも SNS や動画のアプリを入れないことが前提です。

もう触ってしまった日は、どうするか

1日崩れても、ルールは捨てません。次の日から同じルールに戻ります。崩れる日が週に何度もあるなら、ルールが合っていない合図です。自分を責めるより、5つの方法のうち1つ下に進むと決めてください。

外に持つ1台の選択肢

私たち Soto Phone は、SNS・ゲーム・動画・ブラウザを入れない携帯電話を作っています。あとから入れることもできません。電話・SMS・地図・乗換・天気・カメラ・音楽は使えます。LINE の扱いは、発売前に決めてお知らせします。今はまだ開発中で、受験に間に合う時期を約束できる段階ではありません。それでも、受験が終わったあとも「スマホは家に、外ではこれ」という使い方を続けたい人に向けて作っています（Soto Phone とは）。
