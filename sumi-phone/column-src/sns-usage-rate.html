いちばん使われている SNS は LINE で、利用率は92.9%です。次が YouTube の81.5%、Instagram の54.8%でした。総務省が2025年12月に13〜79歳の1,800人に行った調査の報告書（2026年6月公表）から、主な SNS の利用率を年代別・男女別にまとめました。

先に結論

  • 全年代の利用率は、LINE 92.9%、YouTube 81.5%、Instagram 54.8%、X 44.7%、TikTok 36.7%、Facebook 27.0%
  • LINE は10代〜60代のすべてで90%を超える
  • 10代は TikTok が67.9%、20代は Instagram が82.6%、X が73.4%

全年代のランキング

報告書では、Instagram と TikTok の利用率が上がっていることにふれています。

数字を見るときの注意

  • この調査の「利用率」は、調査の対象者のうち、そのサービスを使っていると答えた人の割合です
  • どれくらいの頻度で使っているかは問いません
  • YouTube は動画サービスですが、調査では SNS などの一つとして聞いています

どれくらいの時間を使っているかは、SNSの利用時間の平均にまとめています。LINE なしで暮らせるかは、LINE をやめたらどうなるかをご覧ください。

まとめ

  • 利用率は LINE 92.9%、YouTube 81.5%、Instagram 54.8%、X 44.7%、TikTok 36.7%（2025年度）
  • 10代は TikTok、20代は Instagram と X の利用率が高い
  • Instagram と TikTok は女性のほうが高い
