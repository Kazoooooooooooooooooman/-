見たくて開いたはずなのに、閉じたあと少し疲れている。友だちの投稿を見て、なんとなく落ち込む。返信をしないといけない気がして、落ち着かない。それが SNS 疲れです。かといって、アカウントを消すのは不安。この記事では、SNS 疲れの原因を3つに分け、アカウントを消さずに距離をとる方法をまとめます。

先に結論

  • SNS 疲れの原因は「比べてしまう」「返さなきゃと思う」「終わりがない」の3つ
  • 実験では、SNS を1日30分ほどに減らした大学生は、3週間で孤独感と落ち込みが減った
  • アカウントは消さなくていい。時間・通知・置き場所・見る相手を変える
  • いちばん効くのは、アプリをホーム画面から外すこと

SNS 疲れの正体は、3つ

  • 比べてしまう：SNS には、人の生活のいちばん良いところが並びます。それと自分のふつうの毎日を比べて、落ち込みます
  • 返さなきゃと思う：既読、いいね、コメント。反応しないと悪い気がして、気が休まりません
  • 終わりがない：下にスクロールすれば、いつまでも次が出てきます。やめるきっかけがないので、疲れるまで続きます

自分の疲れがどれに近いかで、効く対策が変わります。ほかの人がどれくらいスマホを使っているかは、日本人のスマホ平均使用時間にまとめています。

減らすと、気持ちは軽くなる（研究から）

アメリカのペンシルベニア大学の Hunt らは、143人の大学生を2つのグループに分けて、3週間の実験をしました。

  • Facebook・Instagram・Snapchat を、それぞれ1日10分まで（合わせて約30分）に減らすグループ
  • いつもどおり使うグループ

結果、減らしたグループは、いつもどおりのグループに比べて、孤独感と落ち込みがはっきり減りました。また、両方のグループで、不安や「見逃しているかもしれない」という気持ちが下がりました。研究者は、自分の使い方を記録して見るだけでも効果があったのだろうと考えています。

つまり、ゼロにしなくても、減らすだけで気持ちは軽くなります。

アカウントを消さずに離れる4つの方法

  1. 時間を決める（終わりがない対策）：1日の上限を決めて、スマホの機能で区切ります。iPhone はスクリーンタイム、Android は Digital Wellbeing のアプリタイマーで設定できます（スクリーンタイムの設定）
  2. 通知を切る（返さなきゃ対策）：いいねやおすすめの通知は切り、人から直接届くメッセージだけ残します（切っていい通知、残す通知）
  3. アプリをホーム画面から外す（終わりがない対策）：アプリは消さず、ホーム画面のアイコンだけ外します。開くのにひと手間かかるだけで、なんとなく開く回数が減ります
  4. 見る相手を選び直す（比べてしまう対策）：見ると落ち込むアカウントは、フォローを外すか、ミュートします。相手に知られずに表示を減らせる機能がある SNS も多くあります

それでも疲れるときは

  • 「見る日」と「見ない日」を分ける：毎日少しずつより、週に何日か完全に離れるほうが楽な人もいます
  • 投稿をやめて、見るだけにする：反応を気にする疲れは、投稿をやめると大きく減ります
  • SNS の入っていない携帯を持つ：外にいる時間だけでも SNS から離れたい人は、SNS もゲームもいらない人の携帯の選び方も参考にしてください

まとめ

  • SNS 疲れの原因は、比べる・返さなきゃ・終わりがない、の3つ
  • 1日30分ほどに減らすだけで、孤独感と落ち込みが減ったという実験がある
  • アカウントは消さずに、時間・通知・置き場所・見る相手を変える
  • 今日やること：いちばん長く使っている SNS のアイコンを、ホーム画面から外す
