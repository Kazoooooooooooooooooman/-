LINE を使わずに暮らすことは、2026年の日本でもできます。家族や友だちとのやり取りは、電話番号だけで使える標準のメッセージアプリで、ほとんど代わりがききます。困りやすいのは、学校・部活・グループの連絡です。この記事では、LINE の代わりになる手段と、困る場面ごとの乗り切り方をまとめます。

先に結論

  • 2026年9月から、ドコモ・au・ソフトバンクのすべてで、iPhone と Android の間でも標準のメッセージアプリ（RCS）で無料のやり取りができる
  • 相手が RCS を使っていなくても、SMS（1通3.3円から）で必ず届く
  • 困るのは、学校・部活・グループの連絡と、LINE でしか手続きできないサービス。前もって「連絡は電話番号で」と伝え、家族の LINE で受け取る方法もある

LINE は、どれくらい使われているか

総務省の2025年度の調査では、LINE の利用率は92.9%で、ほかの SNS より大きく上回っています。LINEヤフーの発表では、国内の月間利用者数は1億を超えました（2025年12月時点）。

ほとんどの人が使っているからこそ、「LINE をやめたら、連絡が取れなくなるのでは」と心配になります。でも、相手が LINE を使っていても、こちらが LINE を使わずに連絡を取る方法はあります。

LINE の代わりになる連絡手段

1. 標準のメッセージアプリ（RCS）

いちばんの代わりは、スマホに最初から入っているメッセージアプリです。iPhone の RCS は、au が2025年4月、ソフトバンクが2026年3月に始めました。2026年9月にはドコモの iPhone も iOS 27 から対応し、国内3社すべてで、iPhone と Android の間で RCS が使えるようになりました。

  • 電話番号だけで送れる（アカウントの登録はいらない）
  • 写真・動画・グループでのやり取りができる
  • 多くの場合、申し込みはいらず、送受信の料金は無料（データ通信は使う）
  • 相手が RCS を使っていない場合は、自動で SMS として送られる（このときは SMS の料金がかかる）

iPhone なら「メッセージ」、Android なら「Google メッセージ」がこのアプリです。

2. SMS（ショートメッセージ）

電話番号さえあれば、どの携帯にも届きます。ドコモでは、全角70文字までなら1通3.3円（税込）で、受け取るのは無料です。ガラケーやシンプルな携帯を使っている相手にも、確実に届くのが強みです。

3. +メッセージ

ドコモ・au・ソフトバンクが2018年5月に始めた、電話番号で使えるメッセージアプリです。利用者は4,000万人を超えました（2024年2月）。ただ、Android では各社の標準アプリが Google メッセージに切り替わっています（au は2024年から、ドコモとソフトバンクは2026年3月以降の新機種から）。今から新しく使い始めるなら、標準のメッセージアプリ（RCS）がおすすめです。

4. 電話

急ぎの用事や、細かいことを決めるときは、電話がいちばん早く終わります。文字のやり取りを何往復もするより、1分の電話のほうが早いことは少なくありません。

5. メール

長い文章や、ファイルを送るときは、Gmail などのメールが向いています。仕事や学校の書類のやり取りは、もともとメールのほうが合っています。

困る場面と、乗り切り方

友だちのグループ

いちばん多いのが、遊びの約束や、クラスの友だちのグループです。

  • 「LINE はやめた。連絡は電話番号のメッセージでお願い」と、最初に伝える
  • グループの中の1人に、大事な決まりごとだけ転送してもらう
  • RCS ならグループでのやり取りもできるので、仲の良い数人とは RCS のグループを作る

学校と保護者の連絡

学校からの連絡は、LINE ではなく専用のアプリを使う学校が増えています。たとえば小中学校向けの「tetoru」は、2026年3月時点で6,300校以上が導入していて、公立学校なら基本の機能は無料です。高校向けの「Classi」、自治体が導入する「すぐーる」などもあります。

LINEヤフーが小中学校の教員と保護者に行った調査では、2つ以上の連絡手段を使っている人のうち、保護者の89%、教員の87%が「1つにまとめてほしい」と答えています。学校の連絡は、学校や自治体が決めたアプリで受け取る形に変わってきています。

部活・習いごと・PTA

部活や地域の集まりでは、LINE のグループで連絡を回すことがまだ多いです。

  • 顧問やコーチに「LINE を使っていないので、電話番号かメールで連絡がほしい」と伝える
  • 「BAND」のような、掲示板と出欠確認ができるグループ用アプリを提案する
  • 子どもの部活なら、保護者の LINE で受け取って、子どもに伝える

教員と生徒が LINE で個別に連絡を取ることを、制限する教育委員会もあります（静岡県や沖縄県など）。学校の部活なら、LINE 以外の方法で連絡がほしいと伝えて、断られることはほとんどありません。

LINE でしか手続きできないサービス

お店のクーポン、予約、自治体の LINE 公式アカウントなど、LINE でしか受け取れない情報もあります。LINE 公式アカウントで情報を出す自治体も多いですが、同じ情報はふつう、ホームページやメールでも出ています。LINE でしかできない手続きが必要なときだけ、家族のスマホやパソコンの LINE を使う、という分け方もできます。

LINE を使わない連絡を、うまく続けるコツ

  1. 先に伝える：「LINE はやめた。電話番号のメッセージか電話で」と、よく連絡する人に最初に伝えておく。あとから気づかれるより、ずっと楽です
  2. 返事のしかたを決めておく：既読がないので、「見たら一言返す」と決めておくと、相手も安心します
  3. 受け取り口を1つ残す：家族の LINE や、パソコンの LINE など、どうしても LINE が必要なときの受け取り口を1つだけ決めておく

私たち Soto Phone の携帯には、SNS は入れていません。電話・SMS（メッセージ）は使えます。LINE の扱いは、発売前に決めてお知らせします（Soto Phone とは）。連絡のための道具と、時間を吸う道具を分けることが、スマホとの付き合い方を変える近道だと考えています。

  • 友だちや部活には先に伝え、どうしても必要なときの受け取り口を1つ残しておく
