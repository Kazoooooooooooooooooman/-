Soto OS 試作（見た目と操作の試作。本物の OS ではありません）
================================================================
soto-os.html 1ファイルだけで動きます（画像も中に入っているので、ネットにつながなくても開けます）。

■ 操作
- ロック画面：上になぞる（またはタップ）で開く
- 画面の下の端から上になぞる：ホームに戻る
- 画面の上の端から下になぞる：クイックパネル（集中モード／白黒／機内モード表示／ライト）
- アプリ：電話・メッセージ・地図・カメラ・乗換・天気・音楽・防災・時計・メモ・スタンプ・集中モード
- 末尾に ?mono を付けて開くと、白黒で始まる

■ 酷派 小方块（720×720）で見せる方法
1. USB ケーブルでパソコンとつなぎ、soto-os.html を端末の「Download」フォルダにコピー
2. 端末のファイル管理アプリから soto-os.html を開き、ブラウザで表示
3. ブラウザの「全画面」または「ホーム画面に追加」を使うと、ブラウザの枠が消えて OS らしく見える
※ 360×360 の画面に合わせて作ってあり、720×720 の画面なら全面にぴったり表示される
※ 日本に持ち帰ったら、機内モードのまま使う（Wi-Fi もオフ）

■ 本物の OS（ランチャー）にするには
Android のホームアプリ（ランチャー）として作り直す必要がある。端末に入れるには、
ODM からの基板のソース一式と署名の鍵、または開発者モード＋USB 経由のインストールが必要。
