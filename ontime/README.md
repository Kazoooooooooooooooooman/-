# ⏰ OnTime — 約束から「起きる・出る・道のり」を自動で逆算

LINE・Gmailで約束が決まったら、そのトークやメールを貼り付ける（またはスマホの「共有」でこのアプリに送る）だけ。
次のものが自動で出てきます。

- **日時と場所を自動で読み取り**：「じゃあ明日14時半に渋谷駅ハチ公前で集合ね」→ 9/26 14:30 / 渋谷駅ハチ公前
  - 会話の中で**最後に決まったもの**を採用。候補が複数あればタップで差し替え
  - 「明日」「来週の水曜」「10/3(土)」「午後2時」「2時半」「14:00~16:00」などに対応
- **道のり**：家→目的地を「到着時刻指定」で Yahoo!乗換案内 / Googleマップ で開く。所要時間と乗る電車を入れると場所ごとに記憶
- **当日のタイムライン（逆算）**
  - 約束 − 早め到着 − 移動 − 遅延保険 ＝ **家を出る時刻**
  - 出発 − 朝の支度（×「気が散る係数」）＝ **支度スタート時刻**（最終起床ライン）
  - 前日の準備・寝る時刻・起床・支度の各ステップを時刻つきで表示
- **アラーム**：`.ics` をカレンダーに追加すると「前日の準備」「起床」「支度スタート」「出発15分前/5分前/出発」が鳴る
- **いまやること**：直近の約束について「今やるべきこと」と「出発まであと何分」を大きく表示
- **ほうれん草（報連相）**：了解の返事 / 前日リマインド / 出発報告 / 遅刻連絡 をワンタップで LINE・メールに送れる。
  遅れそうなときは今の時刻から何分遅れるかを自動で計算

## 使い方

1. GitHub Pages などで `ontime/` を公開して、スマホのブラウザで開く →「ホーム画面に追加」
   （PCなら `index.html` を直接開いても動きます。共有メニューとオフラインだけは https 公開が必要）
2. 最初に ⚙ 設定で「家（最寄り駅）」「いつもの起床時刻」「朝の支度」を入れる
3. 約束が決まったら会話を貼り付けて「読み取る」→ 所要時間を入力 →「保存」「カレンダーに追加」

データはすべて端末内（localStorage）に保存され、外部には送信しません。

## 自動化の範囲について

- LINEは個人トークを外部アプリが読む公式手段がないため、**貼り付け or 共有**で渡す方式です。
  Android ではホーム画面に追加すると、LINE・Gmailの「共有」の送り先に OnTime が出ます（Web Share Target）。
- 所要時間は乗換案内のページで確認して入力します。Google Maps API キーを使えば完全自動化も可能です（今後の拡張候補）。

## テスト

```
node --test ontime/test/*.test.js
```

## SNS版プロトタイプ（chat-demo.html）

`chat-demo.html` をブラウザで開くと、グループトークで「おけ！」と決まった瞬間に
カレンダー登録＋当日の段取り（支度開始・出発・乗る電車）が出るデモを試せます。
電車は中野駅発のデモ経路です。

## 本物の乗換検索を使う（Google Routes API）

プロトタイプ（`chat-demo.html`）は、PCで `server.js` を起動して開くと本物の乗換検索になります。
APIキーはこのサーバーの中だけで使い、ブラウザ側には渡しません。検索内容もログに残しません。

### 1. APIキーを作る（最初の1回だけ）
1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る
2. 「お支払い」でクレジットカードを登録（毎月の無料枠内なら請求は発生しません）
3. 「APIとサービス」→「ライブラリ」で **Routes API** を有効にする
4. 「認証情報」→「認証情報を作成」→「APIキー」
5. 作ったキーを編集して「APIの制限」で **Routes API だけ** に絞る
6. 念のため「予算とアラート」で上限額の通知（例: 1,000円）を設定しておく

### 2. 起動する（Node.js 18 以上が必要）
Mac / Linux:
```
cd ontime
GOOGLE_MAPS_API_KEY=ここにキー node server.js
```
Windows (PowerShell):
```
cd ontime
$env:GOOGLE_MAPS_API_KEY="ここにキー"; node server.js
```
ブラウザで http://localhost:8787 を開く →「個人」タブの「家」に最寄り駅を入れる。
カレンダーの段取り表に「本物の乗換検索」と出ていれば接続できています。
