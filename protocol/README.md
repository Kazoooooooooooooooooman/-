# AgentData Protocol（ADP）試作品

データを売る人と、データを買うAIエージェントを、**5分ごとの自動オークション**でつなぐ仕組みの本物の試作品です。
画面だけのデモ（`../adp/`）と違い、ここでは実際にプログラム同士がつながって、入札・落札・分配が行われます。

```
[売り手]  3行のコード ──→  [ADPサーバー]  ←── 3行のコード  [買い手AIエージェント]
                           5分ごとに競売・落札・分配
```

> 決済は `ledger.jsonl`（帳簿ファイル）に記録するだけで、本物のお金は動きません。Stripe連携は次の段階です。

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `adp_server.py` | オークション会場（サーバー）。ここが会社のプロダクト本体 |
| `adp/` | `import adp` で使う部品（SDK）。売り手・買い手はこれを使うだけ |
| `seller_japanese_qa.py` | 売り手の例：日本語Q&Aデータを出品 |
| `seller_gamer.py` | 売り手の例：ゲームの操作ログを出品 |
| `buyer_simple.py` | 買い手の例：決まった金額で入札するだけ（AIなし・APIキー不要） |
| `buyer_claude.py` | **あなたのAIエージェント**：Claudeがデータを見て入札額を自分で決める |
| `run_demo.py` | 上の全部を一度に起動するデモ |

## 動かし方

### 0. 準備（最初の1回だけ）

1. **Python** を入れる：https://www.python.org/downloads/ （3.10以上。Windowsはインストール時に「Add Python to PATH」にチェック）
2. このフォルダをパソコンに持ってくる：GitHubの画面で `Code` → `Download ZIP` → 解凍
3. **ターミナル**（Macは「ターミナル」、Windowsは「PowerShell」）を開いて、このフォルダに移動：
   ```bash
   cd ダウンロードしたフォルダ/protocol
   ```

### 1. まずはAIなしで動かしてみる（無料）

```bash
python run_demo.py
```

ブラウザで **http://127.0.0.1:8787** を開くと、出品・入札・落札・売り手の収益がリアルタイムで見えます。
デモでは1ラウンドを20秒に短縮しています。止めるときは `Ctrl + C`。

（Macで `python` が見つからないと言われたら `python3` に読み替えてください）

### 2. あなたのAIエージェントを参加させる（Claudeの利用料がかかります）

1. https://console.anthropic.com でアカウントを作り、クレジットをチャージして **APIキー** を発行
2. Claude用の部品を入れる：
   ```bash
   pip install anthropic
   ```
3. APIキーを設定（**キーは人に見せない・GitHubに載せない**）：
   ```bash
   # Mac / Linux
   export ANTHROPIC_API_KEY="sk-ant-..."
   # Windows (PowerShell)
   $env:ANTHROPIC_API_KEY="sk-ant-..."
   ```
4. もう一度デモを起動すると、`[claude ]` という行で、あなたのエージェントの判断と理由が流れます：
   ```bash
   python run_demo.py
   ```
   落札したデータは `downloads/` フォルダに保存されます。

### エージェントの性格を変える

`buyer_claude.py` の上のほうにある `NAME`・`GOAL`・`POLICY`・`BUDGET_USD` を書き換えるだけです。
使うモデルは `MODEL`（標準は `claude-opus-5`）。料金を抑えたいときは `claude-haiku-4-5` に変更できます。
Claudeが安全上の理由で判断を断った場合は、自動で別のモデルが代わりに判断する設定（`fallbacks`）にしています。

### 本番どおり5分ごとに動かす

ターミナルを分けて、1つずつ起動します：

```bash
python adp_server.py            # 1つめ：会場（5分ごと）
python seller_japanese_qa.py    # 2つめ：売り手
python buyer_claude.py          # 3つめ：あなたのAIエージェント
```

## オークションのルール

- 5分ごとに、その間に届いたデータを種類（スキーマ）ごとにまとめて1ロットとして出品
- **封印入札・セカンドプライス**：各エージェントは他の入札額を見ずに入札。最高額が落札し、支払いは2番目の金額（なければ最低落札価格 $10）
- 支払いの **90% を売り手**（出したデータ件数に比例）、**10% がプロトコル手数料**
- 落札したエージェントだけが、そのロットのデータをダウンロード可能
- 買い手には売り手のキーは見えず、仮名（`supplier_xxxx`）だけが見える

## まだないもの（次の段階）

- 本物の決済（Stripe）と、売り手への送金
- 売り手・買い手の本人確認と、ちゃんとしたAPIキーの発行
- データの品質チェック・個人情報の除去
- インターネット上への公開（今は自分のパソコンの中だけで動きます）
