# ClaudeFinance — USD/JPY 週末方向検出

2026/5/9 (土) ・ 5/10 (日) のドル円について、**週末は外為市場クローズ**であることを
踏まえつつ、「次回オープン (NZ/シドニー = 月曜早朝) でどちら方向へ飛ぶ可能性が高いか」
をリアルタイム推定するブラウザダッシュボード。

## 使い方

`index.html` をブラウザで直接開くだけ。ローカルサーバ不要。
30秒ごとに [exchangerate.host](https://exchangerate.host) (APIキー不要・CORS可) から
USD ベースで JPY/EUR/GBP/CHF を取得し、以下の合成シグナルで方向を出します。

| シグナル | 重み | 内容 |
|---|---|---|
| モメンタム | 0.25 | 5/15/60ティック前との方向一致度 |
| 金曜引け乖離 | 0.25 | 2026-05-08 終値からの距離 |
| USD強弱 | 0.20 | EUR/GBP/CHF 平均からの USD 強度 |
| 円クロス | 0.20 | EURJPY/GBPJPY の整合性 |
| 週末バイアス | 0.10 | リバランス vs 継続の簡易ヒューリスティック |

ボラティリティ (σ) で確信度を減衰、想定オープンレンジを表示。

> 投機・投資判断ではありません。シグナル可視化用の検出ツールです。
