# バイブコーディング自己修正の教科書

AIにコードを書かせる「バイブコーディング」で、自分でエラーを直せるようになるための実践教科書（PDF）。

## 成果物
- `バイブコーディング自己修正の教科書.pdf` — 完成版（A4・全43ページ）

## 構成
- `chapters/` — 章ごとのHTMLフラグメント（番号順に連結される）
- `style.css` — 組版スタイル（表紙・本文・コールアウト・表・コードなど）
- `build.py` — フラグメントを連結し PDF を生成するビルドスクリプト

## ビルド方法
```bash
pip install weasyprint
python3 build.py
```
日本語フォントとして IPAGothic を使用しています。
