万能チェックリスト集

● プロジェクト開始時

  • git init して最初のコミットを作った
  • 作るものの「ゴールを一文」で書いた
  • 「動作確認1回分」のステップに割った
  • APIキー等を入れるなら .gitignore を用意した

● AIにコードをもらった直後

  • 何をするコードか、要点を理解した（テンプレ③）
  • 危険な操作が含まれていないか確認した（テンプレ④）
  • 意図しない箇所まで変わっていないか git diff で見た

● エラーが出たとき

  • コードに触る前に、まず一番下から読んだ
  • 種類・場所・説明の3点を拾った
  • 直前に変えた場所を第一容疑者にした
  • 解けなければ、テンプレ①で情報を揃えて聞いた

● 「完成」と言う前

  • 正常・空・変の3パターンを自分で動かした
  • 境界値（端っこ）を試した
  • 直した後、周辺機能の回帰チェックをした
  • 動く状態でコミットした
  • 公開するなら、秘密情報が混ざっていないか確認した
この章の使い方 4つのテンプレを、すぐ呼び出せる場所（メモアプリ等）にも貼っておく。 作業中はこの章を開きっぱなしにして、迷ったらチェックリストを上から潰す。 質問の型と確認の型を、道具として常備するのが、最短で安定する近道。
